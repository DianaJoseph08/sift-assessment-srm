SRM SIFT AI Assessment Platform

Student Study Guide & Demo Preparation Material

Overview: This application is a fully autonomous AI-driven recruiting platform designed to automate the screening and technical interviewing of candidates using advanced Large Language Models (LLMs) and real-time computer vision proctoring.

1. Core Features to Understand

During the demo, you will see the system perform several complex operations. Here is what the application does:

📄 Resume Shortlisting

The system reads resumes (PDF, DOCX) and scores them against specific job requirements using AI. It extracts skills, calculates years of experience, and assigns an overall Resume Fit Score.

🤖 Conversational AI Interview

Candidates are sent a unique link where an AI conducts a live, conversational technical interview. The AI acts as a strict technical interviewer, generating highly specific, skill-verifying questions to catch candidates who exaggerate on their resume rather than asking generic behavioral questions.

👁️ Live Face & Event Proctoring

While the candidate takes the interview, the system uses MediaPipe Machine Learning to track their eye movements (gaze tracking and head pitch). It utilizes smart context-awareness (e.g., relaxing downward gaze rules on mobile devices to prevent false flags) while tracking tab-switches and copy-pasting to calculate an Integrity Score.

📊 Recruiter Dashboard

Recruiters get a unified dashboard where they can see radar charts of candidate skills, generate interview links, and immediately view the final AI evaluations (Technical and Communication scores) directly on the candidate card.

2. Technology Stack

The application is built on a modern web stack:

  • Frontend React.js (Vite) - Manages the dynamic user interfaces for both the dashboard and the remote interview module.
  • Backend Node.js & Express - Serves the API endpoints, handles secure prompt formulation, and interfaces with the database.
  • Database SQLite - A lightweight, file-based database that stores job postings, candidate extracted data, and interview logs.
  • AI Brain Google Gemini 2.0 Flash - Used to extract JSON data from messy resumes, and acts as the strict judge evaluating candidate interview answers.
  • Computer Vision Google MediaPipe - Runs directly in the browser via WebAssembly to track facial landmarks without sending video frames to a server, ensuring low latency and privacy.

3. The Architecture Workflow

When studying the application, visualize this flow of data:

  1. Input: Recruiter uploads a Job Description and a batch of Resumes.
  2. Extraction: The Node.js server sends the text to the LLM (Gemini/Claude) which replies with structured JSON grading the candidate.
  3. Deep Skill Verification: The LLM crosses the candidate's claimed skills with the job's must-haves to generate 5 deep, technical questions tailored to verify authenticity.
  4. The Interview Loop: The candidate opens the interview link. The browser accesses the Webcam, uses Speech-to-Text (Web Speech API) to record answers, and Text-to-Speech to read questions aloud.
  5. Evaluation & Sync: Upon finishing, the transcript and the Proctoring Log are sent back to the server. The AI calculates a Technical Score, which is then immediately synchronized back to the SQLite Database and updated on the recruiter's dashboard.

4. What to Watch for During the Demo

  • Smart Proctoring Alerts: Notice how the system flags a candidate if they look away from the screen. Watch how the system is context-aware: it catches quick downward glances at mobile phones on a laptop, but smartly disables this penalty if the user is actually taking the interview *on* a mobile device.
  • Strict AI Grading: Watch what happens if a candidate provides a short, irrelevant, or vague answer. The AI is programmed with strict rubrics to penalize bad answers (scoring them under 50%), rather than being overly polite.
  • Deep Skill Testing: Observe the interview questions. They will not be generic (e.g. "tell me about yourself"). They will directly challenge the candidate on specific technologies they listed on their resume.
  • Data Visualization: Observe the Radar Charts and the newly added AI Interview Score badges in the candidate dashboard that visually represent skill match and performance.
